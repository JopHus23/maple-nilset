# Markdown 语法教程

本文档列出当前应用支持的 Markdown 语法。主页公告和随心记（后续）均使用同一套渲染引擎。

## 标题

```markdown
# 一级标题
## 二级标题
### 三级标题
#### 四级标题
##### 五级标题
###### 六级标题
```

## 文字样式

| 语法 | 效果 |
|------|------|
| `**粗体**` | **粗体** |
| `*斜体*` 或 `_斜体_` | *斜体* |
| `***粗斜体***` | ***粗斜体*** |
| `~~删除线~~` | ~~删除线~~ |
| `==高亮==` | ==高亮== |
| `` `行内代码` `` | `行内代码` |

## 代码块

用三个反引号包裹，可指定语言（当前不做语法高亮，仅等宽字体+背景色）：

````
```kotlin
fun main() {
    println("Hello")
}
```
````

## 链接与图片

```markdown
[链接文字](https://example.com)
![图片描述](https://example.com/image.png)
```

链接点击后跳转浏览器；图片会加载显示。

## 列表

### 无序列表

```markdown
- 项目一
- 项目二
  - 嵌套项目
```

### 有序列表

```markdown
1. 第一项
2. 第二项
```

### 任务列表

```markdown
- [ ] 未完成任务
- [x] 已完成任务
```

## 引用块

```markdown
> 这是一段引用。
> 可以多行。
>> 嵌套引用。
```

Obsidian 风格 Callout（后续版本支持交互折叠）：

```markdown
> [!note] 提示
> 这是一个提示。

> [!warning] 警告
> 这是一个警告。
```

## 表格

```markdown
| 列一 | 列二 |
|------|------|
| 内容 | 内容 |
| 内容 | 内容 |
```

## 分割线

```markdown
---
```

## 数学公式

行内公式：`$E = mc^2$`

独立公式块：

```markdown
$$
\int_0^\infty e^{-x^2} dx = \frac{\sqrt{\pi}}{2}
$$
```

## 脚注

```markdown
这里有一个脚注[^1]。

[^1]: 脚注内容写在这里。
```

## 标签

```markdown
#项目 #笔记 #待整理
```

标签以高亮颜色显示，点击可筛选（随心记功能预留）。

## YAML Front Matter

文件开头可以加 YAML 元数据（随心记功能预留）：

```markdown
---
title: 笔记标题
tags:
  - 学习
  - 计划
date: 2026-10-27
---

正文内容从这里开始。
```
